## Learning objectives

By the end of this lesson you will be able to:

- explain the tidy data rules and apply them to a sales or finance list;
- convert a range into an Excel Table and use structured references;
- identify wrong data types, especially numbers and dates stored as text;
- sort, filter and use data validation to keep data clean at the point of entry.

## Key terms

::: terms
Record: one complete item of data, such as one invoice line or one delivery, held in one row
Field: one attribute of a record, such as date, customer or amount, held in one column
Excel Table: a named, structured range created with Ctrl+T that expands automatically and supports structured references
Data type: the kind of value in a cell, mainly number, text, date or logical (TRUE or FALSE)
Data validation: an Excel feature that restricts what can be typed into a cell
:::

## 1. The tidy data rules

Most Excel problems start with how the data was typed, not with the formulas. The statistician Hadley Wickham described "tidy data" (2014): each variable forms a column, each observation forms a row, and each type of observational unit forms a table. In office language:

- One header row at the top, with a short, unique name for each column.
- One record per row: one invoice line, one delivery, one payment.
- One field per column: do not put "Luanda - Cliente X" in one cell when region and customer are two fields.
- No blank rows, no merged cells and no subtotal rows inside the data.
- One kind of data per column: a quantity column contains only numbers.

Reports and totals belong on a separate sheet. Every tool in this course (SUMIFS, XLOOKUP, PivotTables, charts) assumes this shape.

::: quiz
? A sales assistant has a sheet with a bold subtotal row after each province. What is the main problem?
- The bold font slows Excel down || Formatting is not the issue. The subtotal rows are.
* Subtotal rows inside the data will be counted again by sorts, filters and PivotTables || Correct. Totals belong in a report, not in the data list.
- Provinces should be in separate files || One list with a Province column is easier to analyse.
:::

## 2. Excel Tables and data types

Once your list is tidy, click any cell in it, press Ctrl+T, confirm "My table has headers" and click OK. On the Table Design tab, name it, for example Sales.

A Table expands automatically when you add a row below it, so formulas, charts and PivotTables based on it include the new data. A formula typed in one row fills the whole column. You can use structured references, which are easier to read than cell addresses: =SUM(Sales[Amount]) adds the Amount column, and =[@Qty]*[@Price] multiplies values in the same row. Finally, the Total Row (Table Design, Total Row) adds totals that respect filters.

Excel treats text and numbers differently. When no alignment has been applied, numbers align to the right and text to the left. A number that sits on the left, often with a small green triangle, is probably stored as text and SUM will ignore it. Dates are numbers too: Excel stores each date as a serial number (in the standard Windows date system, 1 January 1900 is 1), which is why you can subtract dates. =C2-B2 gives the days between an invoice date in B2 and a payment date in C2, and =TODAY()-B2 gives the age of an unpaid invoice. A date that aligns left is text. You will fix these problems in Lesson 4.

## 3. Sorting, filtering and data validation

For sorting on more than one level, use Data, Sort, then Add Level: for example Province A to Z, then Amount largest to smallest. Select a cell inside the Table, not one column, or you will separate values from their rows.

Press Ctrl+Shift+L to turn filter arrows on or off. A normal SUM still adds hidden rows. The Table Total Row uses the SUBTOTAL function, for example =SUBTOTAL(109,Sales[Amount]), which adds only visible rows.

Data validation stops bad data before it enters. Select the column, choose Data, Data Validation, and set what to allow:

- List: a drop-down of allowed values, typed as Luanda,Benguela,Huambo or taken from a range.
- Whole number or Decimal: for example quantity between 1 and 10000.
- Date: for example dates in the current year only.

On the Error Alert tab, choose Stop so wrong entries are refused. To find existing errors, use Circle Invalid Data.

Function: a built-in formula with a name, such as SUM or IF, that takes arguments in brackets
Argument: an input to a function, separated from the next by a comma

Absolute reference: a cell reference with $ signs, such as $F$1, that does not change when copied

## 1. Formula basics: SUM, AVERAGE and order of operations

Every formula starts with an equals sign. Excel follows the usual order of operations: brackets first, then multiplication and division, then addition and subtraction. =100+50*2 gives 200, but =(100+50)*2 gives 300. When in doubt, add brackets.

=SUM(C2:C200) adds every number in the range. =AVERAGE(C2:C200) gives the mean. AVERAGE ignores empty cells and text, but it includes zeros, so a zero typed for "no sale yet" will pull the average down. =MAX and =MIN give the highest and lowest values, and =COUNT counts cells containing numbers.

A key rule of good spreadsheets is: put inputs in cells, not inside formulas. If the VAT rate or commission rate is typed inside a hundred formulas, someone will miss one when it changes. Put the rate in one labelled cell and refer to it.

::: tip | Excel in Portuguese
In Portuguese Excel, function names are translated (IF is SE, VLOOKUP is PROCV) and arguments are separated by semicolons. The logic is the same.
:::

## 2. IF, SUMIFS and COUNTIFS

IF asks one question and gives one of two answers:

=IF(logical_test, value_if_true, value_if_false)

For example, with actual sales in D2 and target in E2: =IF(D2>=E2,"Target met","Below target"). The test uses comparison operators: = equal, <> not equal, >, <, >= and <=. Text results must be in double quotes. IF can also calculate: =IF(D2>=E2,D2*2%,0) pays a 2% bonus only when the target is met.

SUMIFS adds values that meet one or more conditions. The sum range comes first:

=SUMIFS(sum_range, criteria_range1, criteria1, criteria_range2, criteria2, ...)

With Province in column A, Product in column B and Amount in column C:

- =SUMIFS(C:C,A:A,"Luanda") gives total sales in Luanda.
- =SUMIFS(C:C,A:A,"Luanda",B:B,"Rice 25kg") gives Luanda sales of one product.
- =SUMIFS(C:C,A:A,H2) uses the province typed in cell H2, which is better than typing it inside the formula.

COUNTIFS counts rows that meet conditions and has no sum range:

- =COUNTIFS(A:A,"Benguela") counts orders from Benguela.
- =COUNTIFS(A:A,"Luanda",C:C,">=1000000") counts Luanda orders of 1,000,000 Kz or more.

Operators go inside the quotes. To use a cell, join them with &: =COUNTIFS(C:C,">="&H1). AVERAGEIFS works the same way as SUMIFS.

## 3. Relative, absolute and mixed references

When you copy a formula, Excel adjusts the cell references. A relative reference such as C2 becomes C3 when copied one row down. This is what you want for row-by-row calculations.

Sometimes one cell must stay fixed, such as a commission rate in F1 or a grand total. An absolute reference uses dollar signs: $F$1 does not change when copied. A mixed reference locks only one part: F$1 locks the row, $F1 locks the column. Mixed references are useful for tables that are copied both down and across. While editing a formula, click on a reference and press F4 to cycle through C2, $C$2, C$2 and $C2.

Example: amounts are in C2:C50 and the grand total is in C51. In D2, the share of total is =C2/$C$51. Copied down, it becomes =C3/$C$51, =C4/$C$51 and so on. Without the dollar signs, the second row would divide by C52, which is empty, and show #DIV/0!.

::: diagram matrix | The four reference types | Column locked (no → yes) | Row locked (no → yes)
F$1: row locked, column changes when copied across
$F$1: absolute, nothing changes when copied
F1: relative, row and column both change
$F1: column locked, row changes when copied down
:::

::: quiz
? A commission rate is in cell H1. Which formula in D2 can be copied down for all salespeople?
- =C2*H1 || When copied, H1 becomes H2, H3 and so on, which are empty.
* =C2*$H$1 || Correct. The rate cell is locked, while C2 adjusts for each row.
- =$C$2*H1 || This locks the sales value and lets the rate move, the opposite of what is needed.
:::

A food distributor's branch in Benguela has a Table with 1,240 order lines for October: Salesperson (column A), Product (B) and Amount in Kz (C). The branch manager wants, for each of five salespeople, total sales, number of orders, average order value and whether the 15,000,000 Kz target was met.

The sales assistant, Mário, lists the five names in H2:H6 and types the target in K1. In I2 he writes =SUMIFS(C:C,A:A,H2), in J2 =COUNTIFS(A:A,H2), in L2 =I2/J2 for average order value, and in M2 =IF(I2>=$K$1,"Met","Not met"). He copies the row down. For the first salesperson, I2 shows 16,800,000 Kz and J2 shows 280 orders, so the average order is 16,800,000 / 280 = 60,000 Kz and the target is met.

::: case | The target column that is wrong
Mário copied =IF(I2>=K1,"Met","Not met") down five rows. Three salespeople with less than 15,000,000 Kz now show "Met".

- The amounts must be rounded first || Rounding does not change which side of the target they are on.

::: terms

Lookup array: the column that is searched for the lookup value
Return array: the column that holds the result you want, such as the price
Exact match: a lookup that returns a result only when the value is found exactly
Approximate match: a lookup that returns the nearest band, used for tiers such as discounts
#N/A: the error Excel shows when a lookup value is not found

## 1. How a lookup works

Many office tasks combine two lists. An order export has product codes but no prices. A payments file has customer numbers but no salesperson. Copying values by hand is slow and creates errors. A lookup function does it automatically: "find this value in that column and return the matching value from another column."

Every lookup has three parts: what you look for (the lookup value), where you look (the lookup array), and what you bring back (the return array). The lookup value must be stored the same way in both lists. If the code is 1050 as a number in one list and "1050" as text in the other, the lookup fails.

Keep reference lists, such as the price list or customer list, in their own Tables on a separate sheet, with one row per code and no duplicates.

## 2. XLOOKUP and VLOOKUP

XLOOKUP is available in Microsoft 365, Excel 2021 and later, and Excel for the web. Its structure is:

=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])

With a price list Table called Prices that has columns Code and Price, and the order's product code in A2:

=XLOOKUP(A2,Prices[Code],Prices[Price],"Not found")

XLOOKUP uses exact match by default, can return a column to the left or right of the lookup column, and does not break when columns are inserted.

In Excel 2019 and older versions, use VLOOKUP:

=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])

For example =VLOOKUP(A2,$F$2:$H$500,3,FALSE) searches for A2 in the first column of F2:H500 and returns the value from the third column (H). Three rules: the lookup column must be the first column of the range, the range must be locked with $ before copying, and the last argument must be FALSE for exact match. If you leave it out, VLOOKUP uses approximate match and can return a wrong price without any error.

## 3. Approximate match for bands and handling errors

Approximate match is useful for bands such as volume discounts or commission tiers. Build a small table of lower limits sorted from smallest to largest:

- 0 Kz: 0% discount
- 500,000 Kz: 2% discount
- 2,000,000 Kz: 4% discount
- 5,000,000 Kz: 6% discount

With limits in J2:J5, rates in K2:K5 and the order value in D2:

=XLOOKUP(D2,$J$2:$J$5,$K$2:$K$5,,-1)

Match mode -1 means "exact match or the next smaller value". An order of 2,600,000 Kz is not in the table, so XLOOKUP takes the next smaller limit, 2,000,000 Kz, and returns 4%. The discount is 2,600,000 x 4% = 104,000 Kz. The older equivalent is =VLOOKUP(D2,$J$2:$K$5,2,TRUE), which requires the limits sorted in ascending order.

When a value is not found, lookups return #N/A. Other errors you will meet are #REF! (a reference no longer exists), #VALUE! (wrong type of value, such as text in a calculation), #DIV/0! (division by zero) and #NAME? (a misspelt function name, or a function your version does not have). IFERROR replaces any error with a value of your choice:

=IFERROR(VLOOKUP(A2,$F$2:$H$500,3,FALSE),"Check code")

With XLOOKUP, use its own if_not_found argument instead. Do not wrap every formula in IFERROR from the start. First understand why errors appear, because IFERROR also hides real mistakes such as a deleted column.

Lock and copy: use Table names or $ references
Review misses: investigate before adding IFERROR
:::

## Key terms

::: terms

Delimiter: a character that separates values in one cell, such as a comma, hyphen or semicolon
Duplicate: a record that appears more than once, defined by the columns you choose
Non-breaking space: an invisible character, often from websites or systems, that TRIM does not remove

## 1. Diagnose before you clean

Data from accounting systems, bank statements, emails and colleagues is rarely clean. Before cleaning, scan the data and name the problems. The most common ones are:

- Extra spaces: "Luanda " or "  Cliente B", which break SUMIFS and lookups.
- Inconsistent case: "LUANDA", "luanda", "Luanda".
- Several values in one cell: "1050 - Rice 25kg" or "Silva, Ana".
- Numbers and dates stored as text, aligned left.
- Duplicates: the same invoice exported twice.

Then follow a safe workflow. Keep the raw export on its own sheet and never change it. Clean in helper columns next to the data, or on a copy. Check row counts and totals after every step. When the cleaned column is correct, copy it and use Paste Special, Values to replace the formulas, then delete the helper columns.

::: diagram cycle | Safe data cleaning cycle
Keep raw: save the original export untouched
Diagnose: list spaces, case, combined fields, types and duplicates
Clean: use helper columns, functions and tools
Check: compare row counts and totals with the source
Finalise: paste values and document what you changed
:::

## 2. Text functions

Text functions return a cleaned copy of a value. Write them in a helper column, copy down, and check the result.

- =TRIM(A2) removes spaces at the start and end and reduces double spaces between words to one.
- =CLEAN(A2) removes non-printing characters that some systems add.
- =SUBSTITUTE(A2,CHAR(160)," ") replaces non-breaking spaces with normal spaces, so =TRIM(SUBSTITUTE(A2,CHAR(160)," ")) handles both.
- =PROPER(A2) gives Title Case, =UPPER(A2) and =LOWER(A2) change all letters.
- =LEFT(A2,4) takes the first 4 characters, =RIGHT(A2,3) the last 3, and =MID(A2,6,10) takes 10 characters starting at position 6.
- =LEN(A2) counts characters, which helps to spot hidden spaces: "Luanda" has 6, "Luanda " has 7.
- =VALUE(A2) converts a number stored as text into a real number.
- =TEXT(B2,"dd/mm/yyyy") or =TEXT(C2,"#,##0") turns a value into formatted text, useful for labels. Do not use TEXT on columns you will calculate with, because the result is text.

To join values, use & : =B2&" - "&C2 gives "Luanda - Cliente A".

::: quiz
? =LEN(A2) returns 8 for a cell that shows "Benguela". What does this tell you?
- The cell contains a formula || LEN counts characters in the displayed value, not formulas.
* There are no hidden spaces, because Benguela has 8 letters || Correct. A higher number would point to extra spaces or hidden characters.
- The cell is stored as a number || "Benguela" is text, and LEN works on text.
:::

## 3. Remove Duplicates, Text to Columns and Flash Fill

Three built-in tools on the Data tab do in seconds what formulas do in minutes. They change data once and do not update when the source changes, so use them on a copy.

Remove Duplicates (Data, Remove Duplicates) deletes rows that repeat in the columns you tick. Choose carefully: ticking only Customer would delete every order except the first for each customer. For an invoice list, ticking Invoice Number and Line is usually right. To review before deleting, flag duplicates first with =COUNTIFS(A:A,A2)>1, which shows TRUE for repeated values.

Text to Columns (Data, Text to Columns) splits one column into several. Choose Delimited when a character such as a hyphen or comma separates the parts, or Fixed width when each part has the same length. In the last step you can set a column's format: choose Text to keep leading zeros in codes such as 00125, or Date with DMY order to convert dates typed as day/month/year.

Flash Fill (Data, Flash Fill, or Ctrl+E, available since Excel 2013) learns from examples. Type the result you want for the first one or two rows, such as the first name taken from "Ana Silva", then press Ctrl+E. Excel fills the rest following the pattern. Always check the results, because Flash Fill guesses the pattern and can be wrong on unusual rows.

::: slides
SLIDE Step 1: Copy the raw data | Work on a copy sheet; Note the row count and total | Protect the source
SLIDE Step 2: Split combined fields | Text to Columns or Flash Fill; Set codes to Text to keep zeros | One field per column
SLIDE Step 3: Clean text | TRIM, CLEAN, SUBSTITUTE and PROPER in helper columns | Standard values match
SLIDE Step 4: Fix types and duplicates | VALUE for text numbers; Flag with COUNTIFS, then Remove Duplicates | Know what you delete
SLIDE Step 5: Check and finalise | Compare counts and totals; Paste values and delete helpers | Document the changes

? A customer code column shows 125 instead of 00125 after splitting with Text to Columns. What should you have done?
- Used Remove Duplicates first || Duplicates are not related to the missing zeros.
- Used PROPER on the column || PROPER changes letter case only.
* Set the code column format to Text in the last step of Text to Columns || Correct. Text format keeps the leading zeros.
:::

## Worked example: cleaning a customer payments export in Lubango

A distributor's office in Lubango receives a monthly bank export with 2,150 payment lines. The finance assistant, Rui, needs total payments per customer. His SUMIFS results are too low and some customers appear twice.

Rui copies the export to a new sheet and records 2,150 rows and a total of 96,400,000 Kz. The Description column holds "CLI-0458 PAGAMENTO FACTURA". He uses Text to Columns with the space as delimiter and keeps the code as Text. He finds 40 codes with a non-breaking space and fixes them with =TRIM(SUBSTITUTE(A2,CHAR(160)," ")). COUNTIFS on Bank Reference flags 36 lines exported twice. He removes duplicates on Bank Reference only. The final sheet has 2,114 rows, 2,150 - 36, and the total falls by the value of the duplicated lines, which he lists in a note for his manager.

::: case | Duplicates in the payments export
Rui wants to remove duplicate payments. The export has Date, Customer Code, Amount and Bank Reference. Some customers pay the same amount twice in a month on purpose.
? Which columns should Rui tick in Remove Duplicates?
- Customer Code only || This would delete every payment except the first for each customer.
- Customer Code and Amount || Real repeat payments of the same amount would be deleted.
* Bank Reference only, after flagging repeats with COUNTIFS || Correct. Each real payment has a unique bank reference, so repeats are true duplicates.
- All columns except Date || Real payments on different days would be treated as one.
:::

## Key terms

::: terms
PivotTable: an interactive summary of a data list that groups and totals values without formulas
Field: a column of the source data, shown in the PivotTable Fields list
Values area: where numbers are summarised, for example as a sum, count or average
Slicer: a set of buttons that filters a PivotTable with one click
Refresh: the action that updates a PivotTable after the source data changes

## 1. What a PivotTable does

A PivotTable answers questions such as "What did we sell by province this quarter?" or "Which products grew month by month?" from thousands of rows, without writing a formula. It reads the source data and summarises it in a separate table that you can rearrange by dragging fields.

The PivotTable Fields pane has four areas:

- Rows: categories listed down the side, such as Region or Product.
- Columns: categories across the top, such as Month.
- Values: the numbers to summarise, such as Amount or Quantity.
- Filters: a field used to filter the whole table, such as Sales Channel.

The source must follow the tidy data rules from Lesson 1: one header row, one record per row, no blank rows or subtotals. Make it an Excel Table, so the PivotTable includes new rows when you refresh.

::: diagram steps | Building a sales PivotTable
Prepare: tidy data in a named Excel Table
Insert: Insert, PivotTable, new worksheet
Arrange: fields into Rows, Columns, Values and Filters
Shape: summary type, number format, Show Values As, grouping
Use: sort, add slicers, refresh and check the total
:::

## 2. Building and shaping a PivotTable

To build one, click any cell in your Table, choose Insert, PivotTable, select New Worksheet and click OK. Then drag fields from the list into the areas. For "sales by region", drag Region to Rows and Amount to Values.

Excel usually sums numeric fields, but if the column contains blanks or text it may count them instead. Check the label: "Sum of Amount" or "Count of Amount". To change it, click the field in Values, choose Value Field Settings and select Sum, Count, Average, Max or Min. In the same window, click Number Format and set a thousands separator with no decimals for kwanzas.

Show Values As (in Value Field Settings or by right-clicking a value) changes how numbers are presented. Useful options are % of Grand Total (each region's share), % of Column Total (product mix within each month), and Difference From (change versus the previous month).

To sort, right-click a value and choose Sort, Largest to Smallest. To see which rows make up a number, double-click it: Excel creates a new sheet with the detail records. This is the fastest way to check a surprising result.

::: slides
SLIDE Step 1: Region in Rows | Drag Region to Rows; Drag Amount to Values | First view in seconds
SLIDE Step 2: Fix the summary | Check Sum of Amount, not Count; Set number format with thousands separator | Right measure, readable numbers
SLIDE Step 3: Add months | Drag Date to Columns; Group by Months and Years | Trend across the top
SLIDE Step 4: Add product detail | Drag Product to Rows under Region; Collapse or expand with the buttons | Drill from region to product
SLIDE Step 5: Show shares | Show Values As % of Grand Total | Size and share together

## 3. Dates, slicers and refresh

Months are the most common way to analyse sales. If dates are real dates (not text), right-click any date in the PivotTable, choose Group, and select both Months and Years. Newer versions may group dates automatically. Selecting Years as well as Months is essential when the data covers more than one year, otherwise January 2025 and January 2026 are added together.

Slicers make a PivotTable easy for managers to use. Click inside it, go to PivotTable Analyze, Insert Slicer, and tick fields such as Region or Salesperson. A Timeline (Insert Timeline) works the same way for dates.

A PivotTable does not update automatically. After you add or change source data, right-click it and choose Refresh, or use Data, Refresh All. Before sending a report, compare the PivotTable's grand total with the total of the source Table.

::: quiz
? Your sales data covers January 2025 to October 2026. You group dates by Months only. What happens?
- Excel shows an error || Grouping by months alone is allowed.
- Each month appears twice, once per year || That only happens when Years is also selected.
* The same month from different years is added together || Correct. Select Months and Years to keep each year separate.
:::

## Key terms

::: terms
KPI: key performance indicator, a measure that shows progress against an important objective
Chart type: the form of a chart, such as column, bar, line or pie
Data-ink ratio: the share of a chart's ink that shows data rather than decoration
Conditional formatting: formatting that changes automatically depending on a cell's value
Sparkline: a tiny chart inside one cell that shows a trend
Dashboard: a one-page view of the main KPIs for a specific audience
:::

## 1. Choosing the right chart

A manager looks at a chart for a few seconds. Choose the chart from the message you want to give, not from what looks attractive. Four messages cover most office reports:

- Comparison between categories (sales by region, by salesperson): a column chart, or a horizontal bar chart when names are long or there are many items. Sort from largest to smallest.
- Trend over time (monthly sales, weekly cash): a line chart, with time on the horizontal axis from left to right.
- Composition, or part of a whole (share of sales by channel): a pie chart only with a few slices, otherwise a 100% stacked bar.
- Actual versus target: a column chart with the target as a line (a combo chart: Insert, Combo Chart, set Target to Line).

To create a chart, select the data (or click a PivotTable and use PivotChart) and use Insert, Recommended Charts, then check that its type matches your message.

::: quiz
? A sales supervisor wants to show how monthly sales changed from January to October. Which chart fits best?
- Pie chart || A pie shows parts of a whole, not change over time.
* Line chart || Correct. A line chart shows a trend over time most clearly.
- Horizontal bar chart sorted by value || Sorting by value would break the time order.
:::

## 2. Design rules that managers understand

Edward Tufte, in The Visual Display of Quantitative Information (1983), introduced the data-ink ratio: most of the ink in a chart should show data, not decoration. Apply it with these steps:

::: slides
SLIDE Step 1: Write a message title | "Benguela sales fell 26% in Q3", not "Sales chart" | The title is the conclusion
SLIDE Step 2: Remove clutter | Delete 3D effects, heavy gridlines and borders; Remove the legend if there is one series | Less decoration, more data
SLIDE Step 3: Label directly | Add data labels or label lines at their end; Format numbers in millions of Kz | No guessing values
SLIDE Step 4: Use colour with purpose | Grey for context, one strong colour for the focus | Colour points to the message
SLIDE Step 5: Keep axes honest | Bar and column axes start at zero; Same scale when comparing charts | Honest scales build trust
:::

Starting a column axis at a value above zero makes small differences look huge, so keep it at zero. Line charts can start above zero when the change is what matters, but say so in the label. Avoid using red and green as the only signal, because some people cannot easily tell them apart. Add icons, labels or position as well.

## 3. Conditional formatting and sparklines

Conditional formatting (Home, Conditional Formatting) makes a table easier to read without a chart:

- Data bars show the size of each value inside its cell.
- Colour scales shade cells from low to high, useful for a table of regions by month.
- Icon sets show status, such as arrows for up, flat and down.
- Highlight Cells Rules mark values greater than, less than or equal to a number.
- A formula rule (New Rule, Use a formula) highlights whole rows. With variance in column F, select A2:F20 and use =$F2<0 to colour every row where actual is below target. The $ locks column F while the row changes, as you learned in Lesson 2.

Sparklines (Insert, Sparklines, Line) put a small trend chart in one cell, for example the 12-month trend next to each product's total. They let a manager scan many trends in one column.

Variance is the most common KPI calculation. With actual in D2 and target in E2: =D2-E2 gives the variance in Kz, and =(D2-E2)/E2, formatted as a percentage, gives the variance %. Actual 27,000,000 Kz against a target of 30,000,000 Kz gives (27,000,000 - 30,000,000) / 30,000,000 = -10%.

::: diagram pyramid | One-page dashboard layout
Headline KPIs: 3 to 5 numbers with variance versus target
Trends: line charts of the main KPIs over time
Breakdowns: sorted bar or column charts by region, product or salesperson
Detail: a table with conditional formatting and sparklines
:::

::: quiz
? You select A2:F20 and create the rule =$F2<0. What does the $ do?
- It makes the rule apply only to row 2 || The row is not locked, so it moves with each row.
* It keeps the rule checking column F while the row changes || Correct. Every cell in a row looks at that row's variance in column F.
- It converts the rule into currency || $ in a formula locks a reference and has nothing to do with currency.
:::
